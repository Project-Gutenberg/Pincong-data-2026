**CDT 编者按：**5 月 13 日，据 X 用户 @YesterdayBigcat 的消息：一名位于上海的 AI API 中转站经营者发声明称，自己因运营中转站业务被上海警方刑事拘留 37 天，现已取保候审，但预计后续仍将面临起诉判刑。该经营者还在声明中提醒同行，上海目前可能是打击 API 中转站最严厉的地区之一，且类似执法行动有向全国蔓延的趋势。

API 中转站是一种把境外 AI 大模型 API（OpenAI、Claude、Gemini 等）“转一道手”卖给国内用户的中间服务。经营者先在境外用信用卡或批发渠道买到官方 API key，部署在自建服务器上运行开源中转程序，对外提供一个与官方接口格式相同的代理地址。国内用户把客户端里的官方接口换成中转站地址、再填上中转站发放的 key，就能在不翻墙的情况下直接调用模型，按 token 用量以人民币扣费，通常通过微信、支付宝充值。简单说：中转站等于在国内用户和境外 AI 服务之间架一道 “代收代付” 的中间层，既解决访问问题，也解决付费问题。

大家好，我是西瓜的皮，关于网站的问题的，让大家久等了，这边做一个统一的声明：

首先关于网站的关停：

1\. 网站关停的原因是部分 API 也就是大家非常廉价使用的部分模型，其实是我通过非法的技术手段获取的，已经立案，之前消失的时间就是被行政拘留了 37 天。

2\. 目前是取保候审，除了已经缴纳的退赔退赃，还会有罚款而且肯定会被判刑，当然希望最好的结果就是不进去踩缝纫机，而是判缓刑。

3\. 关于案件时间进展还需要公检法的程序在这做个普及公安：2 个月左右，检察院：1 个月左右法院：预计 1-2 个月时间感谢很多小伙伴私聊我的关心，但是这期间我也是不能具体谈论案件的详细情况的。

4\. 对于我个人而言在之前我也不是很了解这些法律法规的，但是通过这次教学普及了写法律知识，只是这学费真的有点大，也在这边建议大家不要做同类似的事情，目前 AI 发展的快，由于法盲，很可能在不知情的情况下就触发国家法律，那些薄羊毛，逆向，所谓的开源项目很多时候都是违法违规的。虽然我在被立案前不久网站已经在转型接入更多合法的渠道了，希望大家清楚不要走我老路，别说坐牢了，37 天的拘留所已经让我生无可恋了，瘦了 20 多斤我是真不想进去了，之后所有项目我都会先检查违法违规条款等。

关于网站后续的情况：

1\. 先说下网站目前是无法使用的设备等已经被公安机构没收，网站的数据也是作为证据无法更改，另外之前的收入也是没收，我无法提供给大家退款的服务.

2\. 主要有 2 个原因，一个是设备被没收包括手机所以之前的聊天记录都没了，数据我也无法获取，每个人找我私聊也非常麻烦，其次主要的原因是没有能力，包括律师，退赔退赃，和解费用还有之后还会有的罚款，已经几倍超过我之前的收入很多很多，大家也知道我之前的价格可以说真的事极低，因此根本没有赚钱，我也不是想逃避，毕竟确实是我的问题，但是目前阶段真的没有能力。只能说望理解了，我也庆幸之前没让大家充值很多，至少损失不会特别大。我只能这么安慰自己了。

3\. 之后网站我还是会尝试继续开启，接入一些合规的 API，费用肯定会增加，但是我肯定还是选取一些性价比高的。

4\. 趁着这机会也正好对原版的网站做个升级，代码优化，时间的话至少是在中下旬了，功能会逐步开发，比如可能先上最近比较热的 image-2，之后再慢慢补充别的模型。

5\. 新的网站不会对外公开注册，到时候有需要的可以私聊我注册使用。有了这个事情更坚定了之前的想法不做大做强，我的核心还是以自媒体为主，在自己使用 AI 的过程中，会有很多渠道甚至性价比高的方法，而网站就是个载体，共享给到粉丝更方便廉价的使用。

6\. 之后的网站会拆分 3 个部分，一个是类似旧版网站，给一些想直接使用模型不写代码的粉丝使用，其次 API 的部分会单独出来，给到那些想要通过 API 调用的用户使用，最后就是我最初想要做网站的信息模块，比如提示词、Skills，工作流等的分享。

7\. 最后关于积分，之前的会全部作废，都需要购买新的积分，我会开通线上充值渠道，积分也会修改有效期，暂定统一 1 年或者永久有效。

最后还是跟大家说声抱歉，包括之前赞助的精神股东，还有企业用户的，还有其他充值的粉丝，我也不想画饼说什么在完整诉讼后给到一定的补偿，因为可能真的做不到，伤到大动脉了。早期加入的应该都了解，在我力所能及的情况下我是会给到很多活动积分的，只能说看网站的运营情况了。最后还是给大家提个醒，上海可能是最严的，但是 AI 的违法违规肯定之后会很严格普及到全国，请大家不要有侥幸心理，捡了芝麻丢了西瓜，一定要注意做个守法的好公民。
