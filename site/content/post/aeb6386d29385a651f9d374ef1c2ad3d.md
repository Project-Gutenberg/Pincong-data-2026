五、致命的非线性正反馈:

在经历数千年的缓慢积累之后，内部质量逐渐被转移至中高纬度的地壳下方的热点区域，也就是中间惯量轴方向45度附近，这个角度是力矩最大点，内部质量将在此处持续堆积，这就导致了最大转动惯量轴和中间转动惯量轴之间的差值逐渐缩小。

![](data:image/svg+xml;utf8,<svg xmlns='http://www.w3.org/2000/svg' width='1080' height='810'></svg>)

超级地幔柱内部质量从低纬度逐渐向中高位热点区域转移和堆积。

由于南北两个超级地幔柱的质量转移方向刚好相反，堆积点在质量守恒定理的约束下基本上维持对拓，这就相当于锚定了未来的新赤道位置。

但真正的麻烦来自于，当全球出现非线性升温时，地表质量迁移速度也进入了一个非线性正反馈系统，通俗的说就是海洋质量的增加变得越来越快，越来越多。

大洋地壳最薄的地方才5km，这一层薄薄的鸡蛋壳，下方的承托(地幔浮力和粘性)在减弱，上方的海水体积以及质量却出现了非线性的暴增。这层薄薄的鸡蛋壳一旦从最脆弱的大洋中脊和赤道处崩解，将释放大量的自由质量，迅速削减最大转动惯量。

六、角动量守恒怎么解释“同步正反馈”

地表崩解 → Imax 偏 → 自转轴偏（角动量守恒的必然）

自转轴偏 → 离心力重分布 → 赤道带差应力升

差应力升 → 再崩解 → 再偏

每一步都满足角动量守恒，但每一步都在放大扰动——因为 \\mathbf{I} 在变，\\vec{\\omega} 被迫跟着变，而 \\vec{\\omega} 变又改变离心力分布。

这就是“守恒律下的正反馈”：

角动量总量不变，但它在“质量分布”和“自转”之间来回倒腾，越倒越偏。

这个机制中有三个关键变量:

变量1：中间轴逐渐增长，逼近/超过最大轴

这是惯量张量的主轴重排（principal axis reordering）。

地球惯量椭球有三个轴：Imax（赤道向）> Iint（中间）> Imin（极向）

正常态：Imax 与自转轴对齐，赤道是"质量富集带"

若深部质量重组让 Iint 增长到接近 Imax，主轴排序会翻转（Iint 变 Imax）

翻转瞬间，自转轴要"找新家"→ 真极移大跳

物理判据：\\Delta m \\cdot R^2 \\cdot \\sin2\\theta 让 I{\\text{int}} - I{\\text{max}} 趋零。

变量2：赤道方向突然质量亏损

这是浅层相变导致的 Imax 削弱。

赤道带洋壳/软流圈受压 → Te 腰斩、黏度掉 → 蠕变+正断

质量从赤道带"崩解流失" → Imax 减小

Imax 减小 = 它与 Iint 的差距缩小 = 加速主轴翻转

关键：这里不是"搬了多少质量"，是"崩了多少"（Δm\_free）。

我要反复强调的"崩解释放自由质量"，落点就在这里。

变量3：两者同步正反馈

这是最要命的一环，也是极移模型的核心。

赤道亏损 → Imax 降 → 主轴趋近翻转 → 自转轴微偏 → 离心力重分布 → 赤道带差应力再升 → 再崩解

同时：深部质量重组 → Iint 升 → 双重逼近

两条路互相喂养，形成正反馈环

这就是"棘轮"：每转一圈，Te 再损伤一档，敏感性再升一格，下一轮更容易触发。

异丁烯通常通过汽油裂解得到，[矿物油](https://zhida.zhihu.com/search?content_id=781334113&content_type=Answer&match_order=1&q=%E7%9F%BF%E7%89%A9%E6%B2%B9&zhida_source=entity)石油裂解的催化剂通常为SiO2, Al2O3, K2CO3。CoAl2O4与ZnAl2O4可以用于[生物油](https://zhida.zhihu.com/search?content_id=781334113&content_type=Answer&match_order=1&q=%E7%94%9F%E7%89%A9%E6%B2%B9&zhida_source=entity)脂的裂解催化剂，生物油脂[裂解温度](https://zhida.zhihu.com/search?content_id=772142305&content_type=Answer&match_order=1&q=%E8%A3%82%E8%A7%A3%E6%B8%A9%E5%BA%A6&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3Nzg4MTQ2MTUsInEiOiLoo4Lop6PmuKnluqYiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjo3NzIxNDIzMDUsImNvbnRlbnRfdHlwZSI6IkFuc3dlciIsIm1hdGNoX29yZGVyIjoxLCJ6ZF90b2tlbiI6bnVsbH0.NNVSKctF9rNewBoRdIOUafVQ0c01JlH2mSiaCH4YLgk&zhida_source=entity)通常为150-250 oC。矿物油裂解温度为500 oC，压强为7-25bar大气压。异丁烯沸点为-6.9摄氏度C。

最普遍的重新排列碳氢化合物分子的过程是[石脑油重整](https://zhida.zhihu.com/search?content_id=720523601&content_type=Answer&match_order=1&q=%E7%9F%B3%E8%84%91%E6%B2%B9%E9%87%8D%E6%95%B4&zhida_source=entity)。最初的工艺，热重整，是在20世纪20年代末开发的。热重整采用510-565°C（950-1050°F）的温度和中等压力（约40巴（4兆帕）或600磅/[平方英寸](https://zhida.zhihu.com/search?content_id=772142305&content_type=Answer&match_order=1&q=%E5%B9%B3%E6%96%B9%E8%8B%B1%E5%AF%B8&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3Nzg4MTQ2MTUsInEiOiLlubPmlrnoi7Hlr7giLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjo3NzIxNDIzMDUsImNvbnRlbnRfdHlwZSI6IkFuc3dlciIsIm1hdGNoX29yZGVyIjoxLCJ6ZF90b2tlbiI6bnVsbH0.FBdYFYaBMc0yV-n0TbUGngdVfTsl3EIgDTWIBAI3pXw&zhida_source=entity)），从辛烷值小于40的重石脑油中获得辛烷值为70至80的汽油（石油）。产品收率虽然辛烷值较高，但包括烯烃、[二烯烃](https://zhida.zhihu.com/search?content_id=781334113&content_type=Answer&match_order=1&q=%E4%BA%8C%E7%83%AF%E7%83%83&zhida_source=entity)和芳香族化合物。因此，它在储存过程中天生不稳定，往往会形成重质[聚合物](https://zhida.zhihu.com/search?content_id=781334113&content_type=Answer&match_order=1&q=%E8%81%9A%E5%90%88%E7%89%A9&zhida_source=entity)和胶质，从而导致燃烧问题。

到1950年那时英郭采用了一种重整工艺，该工艺使用催化剂来提高最理想汽油组分的收率，同时最大限度地减少不需要的重质产物和焦炭的形成。（催化剂是一种促进化学反应但不参与其中的物质。）在[催化重整](https://zhida.zhihu.com/search?content_id=698422356&content_type=Answer&match_order=1&q=%E5%82%AC%E5%8C%96%E9%87%8D%E6%95%B4&zhida_source=entity)中，与热重整一样，石脑油类材料用作原料，但反应是在氢气H2的存在下进行的，这抑制了不稳定的[不饱和化合物](https://zhida.zhihu.com/search?content_id=772142305&content_type=Answer&match_order=1&q=%E4%B8%8D%E9%A5%B1%E5%92%8C%E5%8C%96%E5%90%88%E7%89%A9&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3Nzg4MTQ2MTUsInEiOiLkuI3ppbHlkozljJblkIjniakiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjo3NzIxNDIzMDUsImNvbnRlbnRfdHlwZSI6IkFuc3dlciIsIm1hdGNoX29yZGVyIjoxLCJ6ZF90b2tlbiI6bnVsbH0.3ZJEFmdwlMAShKeTY7UZs9NMuC6o1wOObE4j4U7TFqY&zhida_source=entity)的形成，这些化合物会聚合成更高沸点的材料。

在大多数催化重整过程中，铂Pt是活性催化剂；它分布在[氧化铝](https://zhida.zhihu.com/search?content_id=781334113&content_type=Answer&match_order=1&q=%E6%B0%A7%E5%8C%96%E9%93%9D&zhida_source=entity)Al2O3载体的表面上。少量的铼、氯Cl和氟F充当催化剂促进剂。尽管铂Pt的成本很高，但该工艺是经济的，因为催化剂的寿命长，获得的产品质量和收率高。主要反应涉及长链烃分解成较小的饱和链，并形成由支链分子组成的异链烷烃。环化合物的形成（从技术上讲，石蜡环化成环烷烃）也会发生，然后环烷烃脱氢成芳香族化合物（与碳键合的[氢原子](https://zhida.zhihu.com/search?content_id=781334113&content_type=Answer&match_order=1&q=%E6%B0%A2%E5%8E%9F%E5%AD%90&zhida_source=entity)较少的环状不饱和化合物）。在此过程中释放的氢气H2是催化重整的宝贵副产品。理想的最终产物是异链烷烃和芳烃，两者都具有高辛烷值。

在典型的重整装置中，石脑油装料首先在氢气存在下通过催化剂床，以去除任何硫H2S杂质。然后将脱硫后的进料与氢气（约五个氢分子比一个烃分子）混合，并加热至500-540°C（930-1000°F）的温度。气态混合物向下通过一系列三个或更多反应器容器中的催化剂颗粒。早期的反应器设计为在约25巴（2.5兆帕MPa）或350磅/平方英寸的压力下运行，但目前的装置经常在低于7巴（0.7兆帕MPa）的压力下操作。因为热量在重整反应中被吸收，所以混合物必须在反应器之间的中间炉中重新加热。

  

煤在800-1000摄氏度下与水蒸气反应形成水煤气，C+H2O—>CO+H2。

甲醇由水煤气去除[硫化氢](https://zhida.zhihu.com/search?content_id=772142305&content_type=Answer&match_order=1&q=%E7%A1%AB%E5%8C%96%E6%B0%A2&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3Nzg4MTQ2MTUsInEiOiLnoavljJbmsKIiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjo3NzIxNDIzMDUsImNvbnRlbnRfdHlwZSI6IkFuc3dlciIsIm1hdGNoX29yZGVyIjoxLCJ6ZF90b2tlbiI6bnVsbH0.U97e4z7oCRr6xkGurkjp16QNF_8h56MMeTYmitORxq0&zhida_source=entity)H2S后，通过催化剂合成制成。1923年，德二的[BASF公司](https://zhida.zhihu.com/search?content_id=720523601&content_type=Answer&match_order=1&q=BASF%E5%85%AC%E5%8F%B8&zhida_source=entity)发明了人工[合成甲醇](https://zhida.zhihu.com/search?content_id=182207611&content_type=Article&match_order=1&q=%E5%90%88%E6%88%90%E7%94%B2%E9%86%87&zhida_source=entity)。BASF公司使用的催化剂是Cr2O3-ZnO，反应温度300-400 oC，25-35MPa，单次产率10%。

1966年，英郭ICI公司发明了CuO-ZnO催化剂，混合Al2O3、V2O5、Cr2O3等，可以在200-300 oC、5-20MPa条件下生产甲醇。

  

从前面的辛烷值可以看出甲醇辛烷值比较高、价格相对低廉，因此[甲醇动力](https://zhida.zhihu.com/search?content_id=710949640&content_type=Answer&match_order=1&q=%E7%94%B2%E9%86%87%E5%8A%A8%E5%8A%9B&zhida_source=entity)和汽油相同大小[甲醇机](https://zhida.zhihu.com/search?content_id=747689330&content_type=Answer&match_order=1&q=%E7%94%B2%E9%86%87%E6%9C%BA&zhida_source=entity)与优质汽油机动力大小是一样的，但是甲醇因为热值低所以消耗燃料速度更快、甲醇消耗燃料量更多。甲醇的缺点是热值只有汽油1/2，也就是说相同加油重量的甲醇汽车、甲的醇飞的机的航程只有汽油汽车、汽油飞的机航程的一半。

活塞螺旋桨机的汽油机重量轻功率比较大的优点，相似重量的柴油机达不到一样的功率，而且还要消耗更多的气缸与曲轴金属、产生更大的自重。

(156 mm) x 6.312 in. (160 mm)，排量3,347 cu. in. (54.86 liters)。
