同时深圳是一座典型的移民城市，大量劳动者在年轻时来到深圳工作，退休后或身体状况变差后返回老家。这意味着：第一，许多原本在深圳生活了几十年的人，最终的死亡事件发生在户籍地或老家，不会被计入深圳的死亡统计；第二，留在深圳直到去世的老年人可能是经济条件较好、有房产和医疗资源的群体，存在 " [健康幸存者偏差](https://zhida.zhihu.com/search?content_id=774911209&content_type=Answer&match_order=1&q=%E5%81%A5%E5%BA%B7%E5%B9%B8%E5%AD%98%E8%80%85%E5%81%8F%E5%B7%AE&zhida_source=entity) "。这个机制会同时拉低深圳的中位数死亡年龄（因为老年死亡人口被" 转移 " 到了其他地区）和拉低深圳的死亡率（0.89‰极低的数字部分源于此）。反过来，这些返乡的老年人会抬高其户籍所在地的死亡率和平均死亡年龄。

综上所述，深圳男性中位数死亡年龄 66.684 岁，与谣言中的 "67.7 岁" 相当接近。一个合理的推测是：某个自媒体作者或者大模型在处理信息时，将深圳这一特殊城市的数据错误地泛化为 "中国男性" 的整体水平，再经过转述和四舍五入，就变成了 "67.7 岁"。当然也不排除还有其他来源，比如对全国数据做了某种错误计算，但深圳数据的 "嫌疑" 确实很大，因为数值上高度吻合。

讽刺的是，原公众号作者花了大量篇幅反复强调的中位数死亡年龄不等于人均预期寿命，且高度依赖人口结构。深圳 65 岁以上人口仅占 3.22%，这个数字放到全国任何一个普通城市都是极端异常的。用深圳的数据代表中国，就好比用一个大学校园里的死亡统计来推断整个国家的寿命水平——校园里死亡的人当然年轻，但那只是因为校园里本来就没有老年人。

然而谣言传播时，这些关键的统计学语境全部被剥离了，只剩下一个触目惊心的数字。大模型 "幻觉" 生成一个数字，自媒体把它当数据引用写成文章，这些文章又被大模型抓取作为训练语料或检索来源，形成闭环。在这种机制下，67.7 这个数字甚至可能根本没有任何原始出处，就是大模型在某次推理中基于模糊的信息拼凑出来的。深圳的 66.684、全国男性人均预期寿命约 74—75 岁、以及网上各种碎片化数据，都可能是大模型 "合成" 出 67.7 的原料之一。

在过去，谣言通常有一个可追溯的源头——某篇文章、某个人的发言、某组被误读的数据。但在大模型时代，谣言可以是 "无中生有" 的，一个从未在任何权威文献中出现过的数字，通过 AI 生成→自媒体引用→AI 再学习的循环，就能获得看似可信的 "来源"。而像深圳中位数死亡年龄这类真实但容易被误读的数据，恰恰为这种循环提供了似是而非的合理性外衣，让谣言更难被识别和反驳。

考虑到很多知乎用户对平均[预期寿命](https://zhida.zhihu.com/search?content_id=774832679&content_type=Answer&match_order=1&q=%E9%A2%84%E6%9C%9F%E5%AF%BF%E5%91%BD&zhida_source=entity)的计算方式存在很多误解（包括但不限于某 UNSW 信息技术硕士），所以下面用翟博士都能看懂的方式简单解释一下计算平均预期寿命的步骤：

第一步：确定 “年龄别死亡率”

统计当年各年龄段（如 0-1 岁、1-4 岁、5-9 岁……）的死亡率。公式为：

该年龄段死亡人数该年龄段平均人口数 mx\= 该年龄段死亡人数该年龄段平均人口数 m\_x = \\frac{\\text{该年龄段死亡人数}}{\\text{该年龄段平均人口数}}

第二步：转换为 “死亡概率”

将死亡率转换为各年龄段的死亡概率 qxq\_x ，估算一个刚活到 x 岁的人，在到达 x+1 岁之前死亡的可能性。

第三步：构建 “[生命表](https://zhida.zhihu.com/search?content_id=774832679&content_type=Answer&match_order=1&q=%E7%94%9F%E5%91%BD%E8%A1%A8&zhida_source=entity)”

从一个假设的 10 万人（或 10 万新生儿）队列开始，逐年用死亡概率扣除死亡人数，算出每个年龄段的尚存人数 lxl\_x 。

第四步：计算 “总人年数”

将所有尚存者从 x 岁开始存活的总时间累加，得出总人年数 TxT\_x 。

第五步：得出预期寿命

用总人年数除以期初尚存人数，就是该年龄的预期寿命。通常所说的出生时预期寿命就是 e0\=T0/l0e\_0 = T\_0 / l\_0 。

*   **预期寿命（life expectancy）**：某个年龄段的人平均还能活多少年。

### 摘要

**1\. 公众并非分不清概念，而是 “硬数据” 更可信**  
[预期寿命](https://zhida.zhihu.com/search?content_id=774838324&content_type=Answer&match_order=1&q=%E9%A2%84%E6%9C%9F%E5%AF%BF%E5%91%BD&zhida_source=entity)是估测，存在模型假设与造假空间；火化年龄是既成事实，造假难、信度高。在信任缺失的环境下，公众自然选择看起来更 “真” 的数据。

**2\. 平均数与中位数的差异，放大了官方数据与普通人感受的差距**  
官方常公布预期寿命的平均数，高阶层寿命更长会拉高均值；而普通人更关注中位数，两者差距越大，公众越觉得官方数据 “与自己无关”。

**3\. 纯反对式辟谣没有信息量，甚至适得其反**  
如今的辟谣标准往往是 “只要数据有一点不对就算假”，哪怕真实值是 67.6 或 67.6999，67.7 也算谣言。这种抠小数点的辟谣，在公众眼里等于什么都没说，反而强化了不信任。

**4\. 官方陷入 “三难”：不说不成，说编的不成，说真的也不成**  
真实数据可能确实不好看——若截面死亡年龄中位数偏低，叠加延迟退休政策，会直接动摇社保契约感与工作意义。官方不公布，谣言占据认知；公布 “好看” 的数字，容易被在野知识分子打脸；公布真实数据，又可能引发信任危机。于是只能进行无实质信息量的反对式辟谣。

**5\. 寿险精算揭示了 “退休即死” 的制度残酷性**  
经典寿险精算模型显示，超过 50 岁后，每延迟退休 1 年，预期剩余寿命大约缩短 3 年。按此推算，65 岁退休者的预期剩余寿命被压缩到极短区间——“退休即死” 虽是极端简化，却精准点出了制度设计的本质。

二. 预期寿命到底是怎么算的？
---------------

既然 “平均死亡年龄” 不够好，那有没有方法评估一个人平均意义上能活到多少岁呢？

### 1\. 如何去估计平均寿命？

首先问一个问题：假如一个箱子里有十张彩票，一张中 0 元，两张中 1 元，四张中 2 元，三张中 3 元，你抽一次奖平均中多少钱？

答案很简单，把钱数和概率相乘然后加起来，0\*0.1+1\*0.2+2\*0.4+3\*0.3 = 1.9 元，就是你平均能中多少元，不难理解是吧？

那么，把 0 元，1 元，2 元，3 元…… 换成 0 岁，1 岁，2 岁，3 岁……，用 0 \* 寿命 0 岁的概率 + 1 \* 寿命 1 岁的概率 + 2 \* 寿命 2 岁的概率 + 3 \* 寿命 3 岁的概率………，不就可以得到平均寿命了吗？

### 2\. 寿命是 0 岁，1 岁，2 岁，3 岁…… 的概率该怎么算？

如果我们可以获得各年龄活到下一岁的概率，比如 0 岁活到 1 岁的概率是 p1，1 岁活到 2 岁概率是 p2，2 岁活到 3 岁的概率是 p3……，

显然寿命 0 岁的概率就是 1-p1

寿命 1 岁的概率就是活到 1 岁但活不到 2 岁的概率，即 p1（1-p2）

寿命 2 岁的概率就是活到 1 岁 2 岁但活不到 3 岁的概率，即 p1p2（1-p3）

…………

这样寿命是 0 岁，1 岁，2 岁，3 岁…… 的概率就能获得了！

### 3\. 各个年龄活到下一岁的概率怎么获得？

初中统计学告诉我们，足够大数据下频率可以代替概率！

所以统计一下每年 0 岁的人里死亡占比 q1，1 岁的人死亡占比 q2，2 岁的人死亡占比 q3……，就可以用 1-q1，1-q2，1-q3 去代表 p1，p2，p3……！

所以，我们通过统计各年龄死亡频率，去获取 p1，p2，p3……

然后用 1-p1，p1（1-p2），p1p2（1-p3）…… 去计算寿命为 0 岁，1 岁，2 岁…… 的概率；

最后计算 0 \* 寿命 0 岁的概率 + 1 \* 寿命 1 岁的概率 + 2 \* 寿命 2 岁的概率 + 3 \* 寿命 3 岁的概率……，这样就可以获得平均寿命的估算方法了，**没错，这就是预期寿命的完整计算方式！**

当然，有个问题是百岁老人以上因为个体数较少，频率代表概率会明显失真（比如说某年 120 岁就一个老人结果顺利活到 121 岁，显然我们不能据此认为 120 岁的死亡率是 0%），所以实践中会通过一些策略去平滑切尾，比如 100 岁以上不区分年龄统一用一个死亡率代表，但是显然因为这部分样本很少，所以对整体预期寿命不会有太明显影响。

三. 基于计算方法该如何去看待 “预期寿命”
----------------------

### 1\. 预期寿命能够有效解决针对 “平均死亡年龄” 计算提出的问题吗？

当然可以！

1\. 所有养老院都失火了导致 80 岁以上老人全噶了，体现在预期寿命上就是所有本来 > 80 岁的寿命分布全部集中于 80 岁，必然导致预期寿命的显著下降

不理解的话还是拿彩票举例子，假如说彩票本来平均中奖额 70 元，但是有一天忽然中奖 80 元以上的奖全都统一只兑奖 80 元多出部分一律不给兑，平均中奖额会下降不是在显著不过吗？

至于大学城和 AB 两地的例子，预期寿命的计算原理决定了预期寿命只与**各年龄死亡率**有关，所以只要大学城大学生死亡率和 A 地的夭折率正常，即使低年龄死亡人数偏多，用预期寿命就可以获得合理结果

### 2\. 预期寿命是 “猜测”“预计” 吗？

不是，从上面的推导过程看，预期寿命是一个标准严谨的客观数据，只要给出各年龄死亡率多少，预期寿命就是完全确定的，不存在任何的猜测空间

至于为什么叫 “预期” 寿命，我只能说，高中数学没有讲过上面这个过程叫求**数学期望**吗？

### 3\. 预期寿命是 “编造” 的吗？

显然，既然预期寿命是根据各年龄死亡率严谨计算出来的，所以你要说预期寿命是 “编造” 的，那只能说明输入统计数据也就是各年龄死亡率是 “编造” 的，那么问题来了，**如果基础的各年龄死亡率都是编的，那你凭啥说包括 “平均死亡年龄” 等所有基于死亡率得到的数据是真实的？**
