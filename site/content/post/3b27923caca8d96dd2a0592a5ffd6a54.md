3NBA 式 "彻底保障"：一个对照模型
--------------------

NBA 之所以被全球运动员羡慕，不是因为某笔钱多，而是因为它用**工会（NBPA）谈判 + 信托基金积累 + 终身保险 + 退役者版税**，把 "基本保障" 做成了**制度化、可累积、可携带、不与 single employer 绑定**的体系。关键特征：

| 保障模块 | 机制要点 |
| --- | --- |
| 养老金（信托制） | 满 3 个赛季即 "归属"（vest），62 岁起领最低约 $56,988 / 年；满 10 年最低约 $215,000 / 年。资金来自篮球相关收入（BRI）的 1%（年约 3100–3500 万美元），由独立信托管理。 |
| 401(k) 与企业配比 | 球员年缴上限 $23,000（税前），NBA 配比 140%（再投 $32,200）。在职时即锁定长期储蓄。 |
| 终身健康 / 伤残保险 | 满 3 年享人寿、意外、残疾、医疗、牙科、视力、处方药保险；满 10 年覆盖家属。2016 年起 NBPA 为退役者买单医保。 |
| 退役者版税（RPA） | 退役球员协会靠游戏（2K）、球衣、肖像、卡牌等团体授权分成，给每位退役者发 "residual"，类似演员重播费。 |
| 转型与再教育 | 学费报销最高 $62,500 / 年；创业、转播、教练培训；NBPA"Off The Court" 退出访谈。 |

**关键制度密码：**在 NBA，"投资者 / 管理者"（球队老板、联盟）与 "福利支付者" 是分离的，中间站着独立工会 NBPA 替球员谈判。

退役后，球员不仅可以继续直接从事篮球工作——教练、球探和球队运营，还被辅导投资、从事投资和实业；电视评论员等等体面而优渥的工作。大量的名人堂和纪念活动时刻将他们推向前台，保持热度，建立大众对运动的持续热爱与忠诚，都有着极大的作用！
