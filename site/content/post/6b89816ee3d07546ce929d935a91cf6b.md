间谍罪（spioneri 等）要求有为外国势力收集情报、危害国家安全的故意，情节严重，刑罚也重得多。

非法描绘受保护对象（olovlig avbildning av skyddsobjekt）是《保护法》下的独立罪名。它不要求证明你有间谍意图，只要你故意或过失拍摄了被明确列为受保护对象的设施，就可能构成违法。

瑞典《保护法》（Skyddslagen 2010:305）对“受保护对象”（skyddsobjekt）有明确规定：如果该对象被特别决定并设立了禁止拍摄/描绘/测量（avbildningsförbud），未经许可拍照就属于违法。相关条款（如第7条和第30a条等）规定，故意（uppsåt）或\*\*过失（oaktsamhet）\*\*违反禁令，均可处罚款或最高一年监禁。

### 🔢 第一个数：入口灌了多少水？

2025年，全国博士招生首次突破**20万**，在学博士生规模达到**75.36万**，毕业博士生**11.29万**，三项数据同步刷新历史纪录。十年前，博士年招生还停留在7万出头，如今已逼近三倍。

医学是这轮扩招里最粗的那根水管之一。医学博士招生规模的年均增长率达到**9.06%**，在博士招生学科中增幅位居前列。

具体到院校：上海交通大学2024年博士拟招3500人，2025年4000人，2026年直接跳到**5000人**；其中**医学院一家就拟招1000人**，覆盖临床医学等7个一级学科博士点。个别院校的临床型医学博士扩招比例甚至**超过了40%**，有医学院校的博士招生规模在一年内从47人跳到160人，增幅**240%**。

**入口的水位在涨，而且医学是涨得最快的那几个专业之一。**

### 🚪 第二个数：出口堵了多少人？

博士扩招不是新闻，真正的新闻是：**扩出来的这些人，原本的出口就已经不够用了。**

国内博士生三年准时毕业率**不足四成**，超六成被迫延期，四年、五年毕业已成常态。临床医学的数据更不体面：全国博士延毕率约四成，**临床医学直接飙到六成**。武汉大学临床医学本博八年制的延毕率，从2018级的约40%，到2019级51%，到2020级**70%**。

也就是说，在“实践成果替代论文”这条通道打开之前，临床医学博士的系统里已经积压了大量**卡在出口处的存量**。而每一个延毕的临床博士背后，是一个已经二十七八岁、规培还没结束、收入接近于零、看着本科同学已经升主治的年轻人。

### 🕳️ 第三个数：分流退出的“蓄水池”，根本没蓄上水

但实际执行是另一回事。2019年我国博士生分流退出人数约**7927人**，相对于当年在学博士生规模，分流退出率大约只有**2%**。一项针对管理者的调查显示，**55.4%**的人认为“淘汰或分流机制流于形式”是培养过程管理中的主要问题。

**入口在猛灌，出口本来就窄，中间的“分流阀”又常年拧不动。**

三个数放在一起，系统的压力往哪里走？

### 🧠 所以，这条“实践成果”通道到底是什么？

我不倾向于把它读成“教育家们终于想通了”。**我更倾向于把它读成一次提前的、体面的泄压。**

如果出口不变，入口继续放，延毕的临床博士只会越积越多。而临床医学博士不是实验室里的沉默群体——他们同时在医院里干活，有同事，有患者，有行业内的横向比较，有“三十岁还在问家里要钱”的现实窘迫。**当足够多受过最高教育、受过最严格专业训练的人，在同一时间段、因为同一个制度瓶颈而集体卡住的时候，系统面临的就不仅仅是一个“教育质量”问题。**

这时候，与其等到压力自己找出口，不如**在制度层面先开一个可控的出口**。让一部分人不必再挤论文那座独木桥，用另一种形态证明自己“够格”，把积压的存量慢慢放出去。这不是什么阴谋，这是任何大型系统在面对结构性堵点时都会做的理性选择。

**但“泄压”和“放水”是两回事。** 泄压阀的直径是设计过的：首批只有5个类别，文件自己写明“仍处在试行探索阶段，不宜‘一刀切’地全面铺开”。翻译、农业、会计、艺术都在队列里，但临床医学先动，恰恰因为它的堵点最疼、存量最大、最需要先松一松。

⚠️ 真问题不在“要不要论文”，在下面这三刀
----------------------

### 第一刀：心内科的标准，凭什么套在皮肤科头上？

北大三院消化内科的段丽萍医生说了一句极其老实的话：“适用于心脏病学的做法，未必适用于皮肤病学。”

临床医学有几十个专科。心内科的实践成果可以是介入策略优化、术后管理路径；皮肤科可能是**罕见病表型库**、**长期随访体系**；急诊科可能是一套分诊流程；病理科可能是**诊断一致性提升方案**。如果教指委强行搞一套“实践成果通用模板”，结果只有两种：要么逼着所有专科往同一个模子里挤，要么标准空泛到无法执行。

所以文件目前只给了方向性原则：重点考察**临床场景下的实际应用价值、技术创新特质，以及对患者诊疗和科室能力提升的实际社会贡献**，而不是理论创新性或期刊影响因子。方向是对的，**但“实际贡献”怎么量化？（说你行你就行，很中国。。。）**一台手术的改进算0.5还是0.8？一个分型体系推广到三家医院算不算“验证”？**这些问题的答案，全部压在临床医学教指委还没发布的《基本要求》里**。

### 第二刀：团队成果里，“你的贡献”到底怎么切？

工程博士的实践成果可以署名、可以拆模块、可以看专利排序。临床实践成果的麻烦在于：一个罕见病分型体系的建立，可能是骨科出病例、影像科出读片、流行病学团队出统计、算法团队出模型。**研究生的个人实质贡献**怎么裁量？

北大试点采用的办法是：申请人详细列明在选题设计、临床资料采集、技术攻关、成果形成各环节的具体工作和占比，导师和团队负责人双重确认。这在个案层面能跑通，但它依赖的是**特定团队内部的高度共识**。换一个导师不愿背书、或者团队内部本身就有贡献争议的环境，这套办法的复制性要打一个巨大的问号。

更隐蔽的风险是诚信监管。传统学位论文有查重系统，临床实践成果形态各异，**没有统一的文本比对标准**，覆盖申请、评审、授予、事后追溯全环节的监管体系目前还没有建起来。论文可以查重，一个AI软件怎么“查重”？

### 第三刀：导师自己靠论文晋升，凭什么指导学生搞实践成果？

这是整个改革里最容易被忽略、但可能最致命的一环。

教育学者熊丙奇点得很透：不少高校教师评价体系仍以论文为核心。一个导师如果自己的职业生涯就是靠SCI堆出来的，他有多大的动力、多大的能力去指导学生做一套临床实践成果？更现实的是，临床医学领域**能写好论文的导师未必能指导高质量的临床成果，临床能力强的医生又未必有高校导师的身份和话语权**。

这不是发几个文件能解决的。它取决于高校愿不愿意投入资源建“双导师制”（校内学术导师+行业临床导师），取决于导师遴选和考核标准是不是真的跟着动，取决于答辩委员会里有没有真正懂临床实践的人坐在那里，而不是一群只会看论文的人。

💼 最尴尬的“两张皮”：毕业不靠论文了，评职称还靠不靠？
-----------------------------

这才是普通学生和家长最该盯住的问题。

学位端在松绑，但医生职业生涯的下一站——**职称评审**——是另一个独立的评价系统。2026年各省卫健委的动作并不同步：

  
  

| 地区/单位 | 论文在职称评审中的位置 |
| --- | --- |
| 国家卫健委直属单位 | 论文不作篇数硬性要求，以病案评价为主 |
| 北京市 | 三级医院临床岗不得将论文、SCI作为评审直接依据 |
| 安徽省 | 可不提交论文，病例评审抽50例 |
| 黑龙江省 | 论文不作硬性要求 |
| 陕西省 | 仍要求至少1篇核心专业论文 |

  

换句话说，一个临床专博凭一套漂亮的实践成果拿到了学位，到了某省评副主任医师的时候，文件告诉他：**代表作请提供论文**。学位改革的逻辑是“用临床贡献说话”，部分省份职称评审的逻辑仍然是“用发表记录筛人”。这两套系统如果不收敛，改革就会卡在中间：学生算得过学位的账，算不过职场的账。

**“不用写论文”从来不是“不用产出”。它换的是产出的形态，不是产出的难度。** 一篇SCI论文可以靠实验设计、数据、写作在相对可控的周期内完成；一个能在真实临床场景里跑起来的实践成果，需要科室配合、数据积累、随访验证、甚至工程团队的协作。它对**资源依赖度**的要求，很可能比写论文更高。

🧊 个人分析：为什么我担心这条政策会像计划生育一样“掉头”，但又不会完全掉头
---------------------------------------

提出一个很尖锐的类比：**会不会过几年政策又变了，就像计划生育一样？**

我的判断分两层。

**第一层：大方向不太可能逆转，但“收紧”是完全可能的。**

计划生育的逻辑是“限制—放开—发现放不开—重新想办法鼓励”，政策的**方向**发生了180度转弯。实践成果替代论文的逻辑是“单一论文出口—多元出口—发现多元出口的质量参差—收紧质量门槛”。它更可能走的不是“掉头”，而是 **“先松后紧”的螺旋**。

具体来说：先让一批人用实践成果毕业，把存量放出去；等通道跑了两三届，案例积累够了，教指委再回过头来**抬高《基本要求》的门槛**。到那时候，“实践成果”可能不再是“论文的替代品”，而变成“比论文更难糊弄的东西”——因为论文可以靠影响因子量化，实践成果只能靠**真实使用、第三方鉴定、患者结局**来证明，而这些恰恰是最难造假、也最费时间的。

**第二层：如果“收紧”来得太快，第一批吃螃蟹的人会成为成本承担者。**

这就是计划生育类比里真正值得警惕的部分：**政策在方向上的反复，伤害最大的从来不是系统，是那些按照上一版规则做了人生决策的个体。** 一个学生如果2027年入学，赌的是“实践成果能毕业”；如果2030年毕业前标准突然抬高，他既没有攒够论文，实践成果又不够“硬”，他就卡在了两套标准的夹缝里。

所以，比起“政策会不会变”，更值得问的是：**标准变化的节奏，会不会给在读的人留出反应时间。** 工程类从2024年试点到2026年扩围用了两年，临床医学的《基本要求》到现在还没出来——这个“慢”，某种意义上是在给系统留缓冲，也是在给个体留信号：**不要用“不用写论文”来做入学决策，要用“不管写不写论文，我手里有没有一件拿得出手的东西”来做。**

🔍 对在读的人说几句不浪漫的实话
-----------------

**旧路没有关。** 政策文件明确保留了传统学位论文申请渠道，不强制二选一。这意味着你不需要在《基本要求》还没发布的时候，拿自己的毕业节奏去赌一个细则还没落地的路径。

**适用范围有硬边界。** 目前放开的是临床医学**专业学位**硕士和博士。口腔医学、公共卫生等其他医学类专业学位暂不适用，临床医学**学术学位**研究生完全不在试点范围内，论文要求照旧。

**等《基本要求》，不要等“感觉”。** 各校的实施细则必须以教指委的《基本要求》为母文件。母文件不出来，学校层面的“我们可以用实践成果毕业了”都只是框架，不是操作手册。工程类从2024年9月试点到2026年扩围用了两年；临床医学人命关天，标准打磨的时间大概率不会更短。

**真正该观察的信号，不是Nature发了什么，是两条：** 临床医学《基本要求》什么时候落地，里面有没有分专科的、可操作的**评价维度**；以及2027年度各省职称评审文件里，“论文不作硬性要求”是继续扩散，还是停在原地。

学位授予只是起点。一个临床医学专业学位博士的职业生涯有三四十年，如果评价他的第一站换了尺子，后面的每一站却没换，这把新尺子就只是一张好看的入场券。

Nature报道的是“不用论文也能毕业”，但水面之下正在发生的，是一个系统在入口猛灌、出口收窄、分流阀卡死的三重压力下，**先给自己开了一个可控的泄压口**。标准还没有写完。写标准的人，比交成果的人，压力更大。而真正需要盯住的，不是今天开不开这个口子，是**这个口子会不会在三年后突然变窄，以及变窄的时候，已经站在里面的人来不来得及退出来。**
