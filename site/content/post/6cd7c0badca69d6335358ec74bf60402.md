[ChatGPT](https://zhida.zhihu.com/search?content_id=758852257&content_type=Answer&match_order=1&q=ChatGPT&zhida_source=entity) 为什么收费，而豆包、DeepSeek 可以免费？说到底是三家公司站的位置完全不同，目标也完全不在一个轨道上。

OpenAI 从一开始就把自己定位成 “靠模型吃饭” 的公司，它没有抖音这样的现金机器，也没有量化这种印钞能力。它的技术一旦开源或免费，大量企业就不会再为 API 付费，投资人也看不到未来的收入增长。你想想，一个靠模型活着的公司，如果模型本身不收费，那它拿什么去付上万张 GPU 的账单？每天全球用户调用上亿次，每一次都在烧算力。OpenAI 不收费，真不是良心问题，而是生存问题。

豆包完全是另一套逻辑。字节跳动的家底厚到什么程度？一个抖音电商都能养活几十个大型研发团队。豆包本质上不是 “赚钱产品”，而是集团生态里的 “效率发动机”。它能提高内容生产效率、推动视频创作流程、给字节内部所有团队带来降本增效的效果，这些价值远超过用户直接付费。对字节来说，豆包免费并不是亏本，而是属于那种 “我用自己的利润补贴你们的模型，让你们更依赖我的生态”，这是巨头们最擅长的打法。你看搜索时代的百度、移动支付时代的支付宝，哪一个不是靠免费迅速占领市场？豆包延续的就是这种打法，根本不急着短期盈利。

DeepSeek 则是最特别的一个。它背后是量化基金幻方，而量化的赚钱速度，在科技行业里属于 “全场最稳的现金流”。量化每天靠数学模型和市场波动赚钱，几亿上下的波动都可能是日常数据。相对这种规模，DeepSeek 的研发成本并不是无底洞，甚至可以作为技术探索、人才吸引、品牌推广的综合投资项目。更关键的是，DeepSeek 的工程路线非常 “抠”，模型设计上就是为了降低算力成本，所以推理成本本身就低得离谱。幻方拿它免费开放，不只是大方，而是经过计算：免费的影响力传播、吸纳人才、扩展生态，这些回报比收费高得多。

这么说，你会发现三家根本不在一个维度竞争：

*   ChatGPT 做的是 “模型产品”，靠收费维持高算力运转；
*   豆包做的是 “生态战略”，靠集团业务反哺大模型；
*   DeepSeek 做的是 “技术外溢”，背后主业赚钱更快，所以模型甚至不需要自负盈亏。

就像你自己月薪两万，你花五百去钓鱼，只是兴趣使然而已；但你要是靠靠钓鱼谋生，那五百块就是成本结构的一部分，不能随便撒。这就是 OpenAI、豆包和 DeepSeek 的关系：一个靠模型吃饭，一个靠生态输血，一个靠主业养副业。

而故事真正有趣的地方在于：虽然三家的定位完全不同，但它们最终共同推动了整个 AI 行业的加速演化。OpenAI 靠收费走出了一条 “商业自循环” 路线；豆包靠免费让更多人能用到大模型；DeepSeek 则靠高性价比打破了行业的成本天花板。从商业和技术的角度看，这三者的组合反而形成了一种类似“生态三角”，互相推动、互相刺激，让竞争比过去任何时候都激烈。

所以，用户今天能免费用到那么多强大的模型，不是因为某家公司突然变得善良，而是因为三家巨头在不同的规则下同时押注 AI，把技术带到了一个 “必须卷” 的时代。

收费也好，免费也罢，本质都是商业策略和资源结构的选择，而不是能力的分高低。

很多人会问：那 DeepSeek 和豆包的成本怎么这么低？一部分来自工程与产品侧的降维打法。DeepSeek 把网页 / APP 做成完全免费的体验层，而在 API 侧用错峰价 + 缓存命中价把成本再砍一刀；训练侧，它在技术报告里给出 V3“约 278.8 万张 H800 GPU· 小时、按 $2 / 小时折算约 $557.6 万”的训练成本下界，引发了全球对低成本也能做强模型的讨论。但多家机构提醒：这只是正式训练账单，不含研发、消融、数据、失败实验与基础设施折旧；同时，DeepSeek 也出现过阶段性价格上调与容量限流的紧张期，这些都在说明 “免费” 更多是一种前台分发策略。

* * *

DeepSeek 的免费，很大程度上源于其技术带来的 “成本优势”。

ChatGPT 的早期模型（如 [GPT-4](https://zhida.zhihu.com/search?content_id=758972721&content_type=Answer&match_order=1&q=GPT-4&zhida_source=entity)）运行极其昂贵。但 DeepSeek 是技术流派的代表，它之所以敢免费，是因为它把推理成本打下来了。

DeepSeek 采用了混合专家模型（[MoE](https://zhida.zhihu.com/search?content_id=758972721&content_type=Answer&match_order=1&q=MoE&zhida_source=entity)）以及独创的 [MLA](https://zhida.zhihu.com/search?content_id=758972721&content_type=Answer&match_order=1&q=MLA&zhida_source=entity)（多头潜在注意力）等技术。简单来说，它让模型变得更 “聪明” 且“省电”。在处理同一个问题时，DeepSeek 激活的参数量可能远小于 GPT-4，导致其推理成本大幅降低。

这种技术上的成本优势，使得 DeepSeek 能够以极低的价格甚至免费提供服务，从而在市场上快速通过 “高性价比” 获取开发者和用户口碑。

* * *

中国和美国的 AI 市场竞争环境完全不同。

美国市场虽然也有竞争，但 OpenAI 具有绝对的先发优势和品牌心智。用户已经认可了 “最强的 AI 需要付费” 这一设定。[Claude](https://zhida.zhihu.com/search?content_id=758972721&content_type=Answer&match_order=1&q=Claude&zhida_source=entity)、[Gemini](https://zhida.zhihu.com/search?content_id=758972721&content_type=Answer&match_order=1&q=Gemini&zhida_source=entity) 虽然紧追，但也基本遵循这一价格体系。

中国市场则极度内卷，中国经历了 “百模大战”。百度、阿里、腾讯、字节、DeepSeek、Kimi 等创业公司都在争夺用户。

在没有任何一家形成绝对垄断之前，谁先收费，谁就会立刻失去用户。

目前的阶段类似于当年的 “千团大战” 或“打车补贴战”，各家大厂都在烧钱换市场份额，现在谈收费为时尚早，首要任务是把对手挤出局。

* * *

中美 AI 公司在 To B 和 To C 的策略侧重不同。

对于 ChatGPT 来说，C 端收费是其收入的重要支柱之一，同时 C 端也是 B 端 API 的广告牌。

而中国公司的 AI 模型则普遍采取 “C 端免费赚吆喝，B 端收费做服务” 的策略。他们把 C 端产品（如豆包 APP、DeepSeek 网页版）看作是展示技术实力的 “样板间” 和收集数据的 “采集器”。真正的收入来源是企业级市场（私有化部署、API 调用、行业解决方案）。为了让企业客户买单，他们必须在 C 端维持高热度和高口碑，而“免费” 是维持热度最好的手段。

✅ **1\. 成本结构不同：ChatGPT 成本极高**
-----------------------------

ChatGPT（特别是 [GPT-4](https://zhida.zhihu.com/search?content_id=760674121&content_type=Answer&match_order=1&q=GPT-4&zhida_source=entity) / GPT-5 系列）属于**最顶级的大模型**，训练成本与推理成本都非常高：

*   [OpenAI](https://zhida.zhihu.com/search?content_id=760674121&content_type=Answer&match_order=1&q=OpenAI&zhida_source=entity) 必须维持全球服务器、显卡集群、带宽、安全审查、数据标注等费用。

➡ 所以它必须收费，否则根本运营不下去。 （你会发现 ChatGPT 免费版功能比 Plus/AoT 少，就是为了降低成本。）

* * *

✅ **2\. 豆包 / DeepSeek / 千问为什么能免费？（目前免费 ≠ 永久免费）**
------------------------------------------------

这里有几个关键理由：

**① 厂商战略补贴**
------------

国产模型现在处于 “生态争夺战” 阶段，厂商更愿意：

*   用 “免费” 吸引大量用户
*   获得训练反馈、数据
*   快速扩大市场份额
*   布局未来的商业场景（[云服务](https://zhida.zhihu.com/search?content_id=760674121&content_type=Answer&match_order=1&q=%E4%BA%91%E6%9C%8D%E5%8A%A1&zhida_source=entity)、[API 收费](https://zhida.zhihu.com/search?content_id=760674121&content_type=Answer&match_order=1&q=API+%E6%94%B6%E8%B4%B9&zhida_source=entity)、to B 合作）

➡ 本质是 **“战略性亏损换用户”**。

像字节的豆包、阿里千问、DeepSeek 都是在巨头支持下，因此可以长期补贴。

* * *

**② 成本更低（开源模型 + 自研算力架构）**
-------------------------

国产模型大多基于：

*   开源权重（如 [Llama 系列](https://zhida.zhihu.com/search?content_id=760674121&content_type=Answer&match_order=1&q=Llama+%E7%B3%BB%E5%88%97&zhida_source=entity)、[Qwen](https://zhida.zhihu.com/search?content_id=760674121&content_type=Answer&match_order=1&q=Qwen&zhida_source=entity) 等）
*   自研裁剪、蒸馏技术（DeepSeek 特别擅长这个）
*   国产云厂商的算力大规模扩容

➡ 单次回答成本比 GPT-4o / GPT-5 低很多。

很多国产模型可以做到 **1⁄20~1⁄50** 的推理成本，因此敢免费放开。

* * *

**③ 商业模式不同**
------------

*   ChatGPT → **面向全球消费者收费（B2C 直接赚钱）**
*   国产模型 → **更看重 B 端 / 政企市场 / 云服务收入**

你现在在淘宝看到 “免费无限” 的 DeepSeek，其实底层是为了：

*   之后推动 API 收费
*   推动云服务
*   推动企业付费升级版

➡ 免费只是入口。

* * *

✅ **3\. 免费并不代表能力更强**
--------------------

很多用户常问：

为啥我感觉 DeepSeek 回复还挺好，那为什么 ChatGPT 还收费？

因为：

*   GPT-5、GPT-4.1、GPT-4o 等「旗舰模型」仍然在推理质量上一致领先
*   特别是**逻辑推理、复杂编程、跨语言能力、生成质量、稳定性**方面
*   AI 越强越费钱，免费模型通常在某些场景强，但整体不会超过旗舰闭源模型
*   国产模型目前主要靠 “性价比优势” 快速抢占市场

简单理解：

**“一辆特斯拉很贵，但并不妨碍五菱宏光（免费模型）也非常好开。”**

* * *

✅ **4\. 后续趋势（非常关键）**
--------------------

可以预见未来：

*   国产模型：**基础服务长期免费，但专业版 / 企业版收费**
*   OpenAI：可能推出更便宜的大众模型，但旗舰模型仍然收费
*   免费模型将越来越强，但短期仍很难完全替代 GPT-5 级别模型

总结：

**OpenAI 是靠产品赚钱，国产模型是靠产业赚钱。 商业逻辑不同，因此出现 “一个收费，几个免费”。**

### 知乎用户  AxiaoYO 发表
    
这个问题下面一定会有两种声音：一种说 "国产 AI 良心"，一种说 "ChatGPT 就是比国产强"。

都对，也都不对。**因为这压根不是一个技术问题，这是一个商业模式的问题。**

先纠正一个认知误区：豆包和 [DeepSeek](https://zhida.zhihu.com/search?content_id=773079676&content_type=Answer&match_order=1&q=DeepSeek&zhida_source=entity) 并不是 "完全免费"
---------------------------------------------------------------------------------------------------------------------------------------------------------

准确地说，它们是 **C 端（个人用户）免费，B 端（企业用户）收费**。

你打开豆包随便聊，一分钱不花。但如果你是个开发者，要通过 API 调用豆包的模型能力嵌入到自己的产品里，对不起，按 token 付钱。[字节跳动](https://zhida.zhihu.com/search?content_id=773079676&content_type=Answer&match_order=1&q=%E5%AD%97%E8%8A%82%E8%B7%B3%E5%8A%A8&zhida_source=entity)当年把豆包的企业定价打到了千 Token 0.0008 元，号称开启了 "厘时代"——但那只是烧钱抢市场的手段，不是真慈善。

DeepSeek 也一样。C 端随便用，但 API 在 2025 年 2 月就恢复了原价，输出 token 的价格直接涨了 4 倍。

**所以本质上，这些 "免费" 产品走的都是互联网经典套路：C 端免费获客，B 端 API 变现。**

就像你免费用 WPS 写文档，但你公司采购 WPS 企业版要花钱。你免费用 360 杀毒，但你公司买 360 企业安全服务要花钱。逻辑一模一样。

那 ChatGPT 为什么不学这个套路？
--------------------

答案很简单：**[OpenAI](https://zhida.zhihu.com/search?content_id=773079676&content_type=Answer&match_order=1&q=OpenAI&zhida_source=entity) 除了 AI，什么都没有。**

字节跳动背后有抖音、TikTok、今日头条这整个商业帝国。豆包免费没关系，你用豆包问怎么做红烧肉，它给你推荐几个抖音上的厨具链接，你用豆包写短视频文案，它建议你发到抖音试试效果——流量最终还是回到了字节的生态里。对字节来说，豆包本质上是一个巨大的**流量入口和生态粘合剂**，不需要自己直接赚钱。

DeepSeek 背后是[幻方量化](https://zhida.zhihu.com/search?content_id=773079676&content_type=Answer&match_order=1&q=%E5%B9%BB%E6%96%B9%E9%87%8F%E5%8C%96&zhida_source=entity)，一家做量化投资的公司，AI 能力本身就是核心竞争力的一部分。开源是为了建生态、招人才、树口碑，短期亏损完全扛得住。

但 OpenAI 不一样。它没有广告业务，没有电商业务，没有社交平台。2024 年仅运营成本就高达 85 亿美元，每天光是跑 ChatGPT 的电费就是一笔天文数字。目前 ChatGPT 大约有 3500 万付费用户，订阅收入占了整个公司营收的大头——OpenAI 的 CFO 亲口说过，大约 75% 的业务来自用户订阅。

**如果 ChatGPT 也免费了，OpenAI 立刻断粮。**

这就是为什么即使面对国产 AI 的免费攻势，OpenAI 依然在 2026 年推出了新的订阅层级（Go 套餐 8 美元 / 月、Plus 20 美元 / 月、Pro 200 美元 / 月）——不是不想免费，是真的免费不起。

训练成本的差距，也是一个关键因素
----------------

DeepSeek 在技术报告里透露，V3 模型的训练成本大约 557 万美元。而 [GPT-4](https://zhida.zhihu.com/search?content_id=773079676&content_type=Answer&match_order=1&q=GPT-4&zhida_source=entity) 的训练成本据传超过 1 亿美元。

这个差距是怎么来的？一方面是国产团队在工程优化上确实下了苦功（比如 DeepSeek 的 [MoE 架构](https://zhida.zhihu.com/search?content_id=773079676&content_type=Answer&match_order=1&q=MoE%E6%9E%B6%E6%9E%84&zhida_source=entity)、[FP8 混合精度训练](https://zhida.zhihu.com/search?content_id=773079676&content_type=Answer&match_order=1&q=FP8%E6%B7%B7%E5%90%88%E7%B2%BE%E5%BA%A6%E8%AE%AD%E7%BB%83&zhida_source=entity)等），另一方面也跟算力成本的地域差异有关。美国的高端 GPU 价格、数据中心电费、工程师薪酬，都远高于国内。

但这里有个容易被忽略的点：**训练成本只是一次性的，推理成本才是持续烧钱的大头。** ChatGPT 要同时服务全球近 9 亿周活跃用户，每一次对话都在消耗算力。免费用户越多，亏得越厉害。

说句大实话：免费的东西，你才是产品
-----------------

豆包免费用，你的对话数据、使用习惯、偏好信息，都在帮字节跳动训练更好的模型、优化更精准的推荐。DeepSeek 免费用，你的使用量在帮它验证模型的稳定性和扩展性，为企业级产品提供背书。

这不是阴谋论，这就是互联网的基本逻辑。**当你不花钱的时候，你的注意力和数据就是你支付的 "货币"。**

ChatGPT 收费，某种程度上反而是更坦诚的交易——我提供服务，你付钱，两清。
