**劳动关系**中，转岗须满足多个条件，例如：不胜任现岗位的，单位不得解雇或强制转岗；经培训后仍不能胜任的，可以转岗，但新岗位不得具有侮辱性（例如看大门、扫厕所等）；待遇不得降低等。

此图表显示，有人转岗后待遇降低，切实享受了一把 “编制的好处”。

**3.2 缓聘**

**人事关系**中，缓聘意味着收入大幅缩水，就同济大学而言，每月 2000 多元（税后）的国家工资总归是有的。

**劳动关系**中，没有缓聘这个概念，用人单位可以故意减少劳动者工作量，但不得故意减少工资。

**3.3 不续聘**

**人事关系**中，不续聘的，事业单位一般无需支付补偿。

当然有例外。鉴于此图表显示有缓聘，每个月发 2000 元，连发一年后再辞退，补偿金 N 就可以每月税前收入（2000 元 + 社保扣除数 + 公积金扣除数）为基数计算，损失最小化，所以个人倾向于认为同济大学属于有辞退补偿的事业单位。

**劳动关系**中，合同到期不续签的，用人单位须支付 N+1 补偿金；提前一个月通知劳动者不续签的，用人单位应支付 N 补偿金。

最近这种有编制的，又出了创新。学校搞了一个[员额制](https://zhida.zhihu.com/search?content_id=784222517&content_type=Answer&match_order=1&q=%E5%91%98%E9%A2%9D%E5%88%B6&zhida_source=entity)出来。简单来说就是有编制，但是编制是学校的，不是跟着你个人的。所以看起来有编制，其实不安稳，学校可以根据考核情况解聘。只能说相对没编制的要强一点。考核的要求跟没编制的比也要轻松一点。工资待遇和考核跟有编的差不多。

然后就是介于编制和没编制之间，有一种新人代。这种比没编制安稳。其他的跟有编制差不多，从考核到工资。但是他不是编制哦。不过目前很多学校按照有编制的进行管理。

最后就是没编的。没编的，很多学校起了很多名字，不要管是[预聘制](https://zhida.zhihu.com/search?content_id=784222517&content_type=Answer&match_order=1&q=%E9%A2%84%E8%81%98%E5%88%B6&zhida_source=entity)还是年薪制。只要没编就是一样的。考核难度大，要求在规定的时间出成果，完成不了就解聘。不过，一般比有编的挣得多。

以上的基本的分类。但是现在又出了一些新玩法。

有编的，但是同时想拿高工资。额外签订一个关于任务的合同，任务完成就按照约定的拿工资，完不成就不好说了。我遇到的就有，完不成拿低工资，或者是完不成不续聘。啥情况都有，看当时的合同。每年不一样。

没编的，也要注意，条件也是每年不一样，不要觉得自己和别人一个学校，要求就是一样的，其实不是。我的经验，仍然是每年不一样。说不好。

事业编聘用制改革后全部都是编制在岗不在人。

所谓「实名编，编随人走；[控制总量事业编](https://zhida.zhihu.com/search?content_id=784959674&content_type=Answer&match_order=1&q=%E6%8E%A7%E5%88%B6%E6%80%BB%E9%87%8F%E4%BA%8B%E4%B8%9A%E7%BC%96&zhida_source=entity)，编随岗走」的说法，完全是改革前入职的老事业编的一种挽尊。

无论是过去事业单位关、停、缩编后，富余人员转岗到其他事业单位。还是现在很多地方都在进行的事业编教师转岗。

本质上都是先跟原本的单位解除聘用合同，再和新单位订立新的聘用合同。

老合同赋予的所谓「事业编制」，不可以延伸到其他单位。

自然，更没有「事业编制，归属于人社局」的说法。人社局只是有权利管事业编，不代表事业编属于人社局。

从制度演进来看，自 2014 年开始国内就正式启动了[预聘 - 长聘制](https://zhida.zhihu.com/search?content_id=784358400&content_type=Answer&match_order=1&q=%E9%A2%84%E8%81%98-%E9%95%BF%E8%81%98%E5%88%B6&zhida_source=entity)改革，目前全国已有超 100 所高校落地，[双一流高校](https://zhida.zhihu.com/search?content_id=784358400&content_type=Answer&match_order=1&q=%E5%8F%8C%E4%B8%80%E6%B5%81%E9%AB%98%E6%A0%A1&zhida_source=entity)中约 70% 都推行了这项制度，核心就是打破职称终身制，建立 “能上能下、能进能出” 的用人机制，考核不合格就要面临调整。

从具体的处理类型来看，目前国内高校针对考核不达标的教师，已经形成了梯度化的处理方式：

1.  **不续聘**：这类情况多数出现在预聘制的助理教授、讲师群体，也就是常说的 “[非升即走](https://zhida.zhihu.com/search?content_id=784358400&content_type=Answer&match_order=1&q=%E9%9D%9E%E5%8D%87%E5%8D%B3%E8%B5%B0&zhida_source=entity)”，即便双非院校现在也普遍推行这一规则；即便是已经晋升为教授、副教授的长聘岗位，也设置了聘期考核要求，达不到标准同样会触发不续聘。[特聘岗位](https://zhida.zhihu.com/search?content_id=784358400&content_type=Answer&match_order=1&q=%E7%89%B9%E8%81%98%E5%B2%97%E4%BD%8D&zhida_source=entity)、高层次人才 “戴帽” 岗位因为享有远高于普通教师的待遇，考核标准更高，一旦不达标基本都会直接不续聘。
2.  **有条件续聘**：多用于考核接近达标、存在提升空间的教师，会给出一定缓冲期要求完成指定目标，达标后恢复正常聘用。
3.  **缓聘 / 暂停招生**：这类情况多针对长期不在校投入精力不足、课程工作量不达标，甚至出现课程交给博士生代讲等情况的资深教师，通常是多年考核不达标后的阶段性处理。
4.  **有条件续聘并降薪**：考核未达标但未满足解聘条件的，会降低岗位津贴与绩效待遇，若下一聘期考核合格可恢复原有待遇。
5.  **转岗降薪**：根据教师的个人能力匹配不同方向转岗：  
    

*   转管理岗：多为科研能力突出且自身有管理意愿、经过轮岗锻炼的教师，属于主动调整路径；
*   转教辅岗：科研能力达不到要求，但熟悉学校课题申报、财务等管理规则，实务能力突出的教师，会转去教辅岗位承担行政支撑工作；
*   转教学型岗：科研指标不达标，但教学质量优秀，达到基础考核要求，有较好育人成果的教师，会转去专职教学岗位，保留教师身份同时降低科研要求与对应津贴。

和公众认知里 “高校教师只有死工资” 不同，当前国内高校教师的收入本身就是多元化的，和美国类似，只是表现形式存在差异：

### （一）基础收入的分层差异

当前国内高校教师基础收入的差距已经十分明显：传统编制内普通教师，年薪大多在 10-20 万区间，中西部地方院校甚至不足 10 万；而高层次人才、特聘岗位的年收入可以达到 50-70 万甚至更高，顶尖领军人才还会配套安家费、科研启动经费等待遇，收入差距最高可以达到数倍，有 “人才帽子” 的教师收入可达普通教师的 2.6 倍，高待遇自然对应高标准考核，不达标被解聘符合权责对等的逻辑。

除了固定的基本工资和绩效，高校教师还有很多合法的多元化收入来源：

### （二）科研与社会服务收入

参与企业横向课题、提供技术咨询、政策咨询服务，是很多理工科、社科领域教师的重要收入补充，部分和产业结合紧密的专业，这部分收入甚至会超过基础工资；也有不少教师会依托自身技术成果创业，或者进入企业担任独立董事、技术顾问，获得额外收入。

### （三）教学相关的补充收入

很多教学能力突出的教师，会参与在线课程建设、面向社会的职业培训、考研考公考证辅导等，获得合规的讲课费用；指导学生参加竞赛、承担班主任、学业导师等额外工作，也会有对应的津贴补贴。

### （四）其他合法副业

和美国高校教师类似，国内不少时间相对灵活的教师也会开展各类合规副业：比如依托专业能力做自媒体内容创作、艺术领域教师承接设计创作项目、法学领域律师兼职、经管领域开展线下培训咨询等等，部分教师的副业收入甚至超过了本职工作的收入。

总体来看，当前国内高校教师体系中，纯粹只拿基础工资的教师已经越来越少，大多会依托自身专业能力拓展收入渠道；而对于高校来说，考核是维持师资队伍质量的必要手段，权责对等、优劳优酬已经成为行业共识，此次事件也进一步说明，高校教师已经不再是传统意义上的 “终身铁饭碗”，无论职称高低，都需要满足岗位的考核要求才能延续聘用关系。

别说是同济，双非高校都这么干。说白了，高校和企业没什么区别了——[KPI](https://zhida.zhihu.com/search?content_id=785144853&content_type=Answer&match_order=1&q=KPI&zhida_source=entity) 不合格走人。全国高校都在执行这套流程，只是在今年格外较真而已。

你以为考上大学就熬出头了？你以为进了高校就上岸了？

以前：考上大学 = 上岸

现在：进了高校当老师 = 跳进了另一个地狱副本

一个博士进来，合同期六年，要求：N 篇顶刊论文 + N 个国家级项目 + N 万科研经费。完不成？

你连十年后的 “毕业即失业” 是什么体验？都不用毕业，直接“签合同即倒计时”。这六年期间你要是偷懒，合同一到期 “感谢参与，门在那边” 。说句扎心的，学校甚至不用给你赔 N+1。那些每天在实验室里通宵点外卖、熬到心肌缺血还要硬撑的青年教师，不就是输在这道 KPI 上吗？
