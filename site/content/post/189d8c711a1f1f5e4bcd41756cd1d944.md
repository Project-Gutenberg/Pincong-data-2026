### 知乎用户 橙时 发表
    
中国最核心的问题，也是最敏感的问题是：一次分配。

去年我国不是提出[三次分配](https://zhida.zhihu.com/search?content_id=784733747&content_type=Answer&match_order=1&q=%E4%B8%89%E6%AC%A1%E5%88%86%E9%85%8D&zhida_source=entity)改革吗？

官方层面上定义的三次分配分别是：

*   初次分配，要 “**多劳多得、技高者多得**”
*   再分配，要 “**用税收、[社保](https://zhida.zhihu.com/search?content_id=784733747&content_type=Answer&match_order=1&q=%E7%A4%BE%E4%BF%9D&zhida_source=entity)等工具，缩小差距**”
*   第三次分配，要 “**鼓励先富带后富，自愿参与公益慈善**”

虽然这三次分配也确实有在做，但实际情况来看，更贴近于：

**一次分配，由[央国企](https://zhida.zhihu.com/search?content_id=784733747&content_type=Answer&match_order=1&q=%E5%A4%AE%E5%9B%BD%E4%BC%81&zhida_source=entity)拿大头、私企拿小头、普通工人【工薪阶层】拿零头**。

这里说的分配，主要指的是 “劳动报酬” 和“[资本报酬](https://zhida.zhihu.com/search?content_id=784733747&content_type=Answer&match_order=1&q=%E8%B5%84%E6%9C%AC%E6%8A%A5%E9%85%AC&zhida_source=entity)”。

从更严格的意义上来说：**一次分配里，劳动者整体拿得偏少，资本拿得偏多；而在资本环节中，国企和大型私企各自拿走了不同路径的优势份额。**

资本报酬中的大部分利润要么沉淀在国企，要么是交给财政，用于公共开支。

而且由于战略层面资源保护思维，**国企 / 央企天然就具备更高的 “[社会信用](https://zhida.zhihu.com/search?content_id=784733747&content_type=Answer&match_order=1&q=%E7%A4%BE%E4%BC%9A%E4%BF%A1%E7%94%A8&zhida_source=entity) / 借贷便捷 / 行业垄断的先发优势”。**

这就从制度上敲定了央国企必定拿到的资本 / 资源 / 责任是最多的，要承担对应的公共支出开销。

但即便如此，央国企的综合薪资待遇普遍还是要比绝大多数私企要好。

并且，一次分配中，**劳动报酬占比长期偏低，在私营部门比较明显。**

说白了，打工人的劳动产出与获得不成正比。

也就是咱们经常调侃的 “大伙再努努力，今年给老板换宝马、明年给老板换嫂子”

收入占总比少的同时，居民的可支配收入里又非常倚重 “工资”。

根据居民住户调查，2024 年，全国居民人均可支配收入 41314 元，全国居民人均工资性收入 23327 元，即**可支配收入中来自工资性收入的比重为 56.5%**。

说白了，绝大多数人并没有多元化的收入，工资拿多少，他们就花多少。

更要命的是什么呢？

### **二次分配主要最后负责人也是居民**。

税收、社保。

我国最大的税收就是间接税【[增值税](https://zhida.zhihu.com/search?content_id=784733747&content_type=Answer&match_order=1&q=%E5%A2%9E%E5%80%BC%E7%A8%8E&zhida_source=entity)】。

增值税是对商品或服务在流通过程中**新创造的价值**部分征收的一种税。

我们作为最终的消费者，实际上是支付了包含所有环节增值税的商品价格【关键小票也不会告诉你增值税比例是多少，对吧？】

至于社保，现在大家讨论最多的一点就是：**社保能不能在未来做到 “收支平衡”**？

因为社保的模式是现付现结，**短期内全国层面没有即期缺口，但长期结构压力巨大。**

短期内，依靠财政补贴、全国统筹调剂，退休金能保证按时足额发放；但中长期看，在人口老龄化的冲击下，整个体系仍面临严峻挑战。

更不要说最近两年，各地社保都开始涨价了。

![](https://images.weserv.nl/?url=https%3A//picx.zhimg.com/v2-20efedfa5c14f22f09237ac48b884236_r.jpg%3Fsource%3D1def8aca)

所以最后盘下来这一圈，你就会发现，怎么好像所有分配最后需要承担的好像都指向同一批群体？

如此一来，问题就大了。

我这两年一直说，以前的政府是 “[生产型政府](https://zhida.zhihu.com/search?content_id=784733747&content_type=Answer&match_order=1&q=%E7%94%9F%E4%BA%A7%E5%9E%8B%E6%94%BF%E5%BA%9C&zhida_source=entity)”，以服务企业为导向，**因为企业真的缴税给政府，所以从逻辑上来说，只需要服务好企业，让企业平稳顺利发展就行**。

一荣俱荣、一损俱损。

这时候，居民端的收入 / 需求是被压制、是被人为性的忽略。

一个典型的例子：学区房是怎么来的？

政策的地区性划分学位 + 户口制度 + 地产全链条介入开发【政企 PPP 模式或者拿地模式】，大家一起合作共赢，最后把房子卖给刚需的家庭。

居民端接盘嘛。

但是[三道红线](https://zhida.zhihu.com/search?content_id=784733747&content_type=Answer&match_order=1&q=%E4%B8%89%E9%81%93%E7%BA%A2%E7%BA%BF&zhida_source=entity)之后，强行摁住房地产泡沫，开始出清之后，地方不得不痛苦的转型。

本来借由这个契机，地方应该由 “**生产型政府**” 转向 “**[服务型政府](https://zhida.zhihu.com/search?content_id=784733747&content_type=Answer&match_order=1&q=%E6%9C%8D%E5%8A%A1%E5%9E%8B%E6%94%BF%E5%BA%9C&zhida_source=entity)**”，也就是 “为居民端服务”。

但很显然，从最近两年供给侧的反内卷政策，到各种企业不断爆出大大小小的事故【小到拖资欠薪，大到人员伤亡】，整个模式依然是按照原有的路径去走。

其实最好的方向，还是劫富济贫，把企业的利润抽税，反过来补贴年轻劳动力，落实《**劳动法**》。

办成事情没有难不难一说，只有想不想的问题而已。

**趋势总会顺着阻力最小的方向去运行**。

人教人百教不会，事教人一教就懂。

国外案例也有很多，也是一样开始不愿意让利给居民端，到今时今日，不也一样是需要提高福利待遇留人？

### **对企业的纵容导致的恶果就是居民端负债且没钱消费、没意愿消费、没能力消费、不敢消费。**

经济的客观规律不由人的意志所转移。

挣扎越久，修复周期越长，无非大家抱着一起互相折磨。

追觅可以视为中国地方政府产业基金 + [资本招商体系](https://zhida.zhihu.com/search?content_id=784823921&content_type=Answer&match_order=1&q=%E8%B5%84%E6%9C%AC%E6%8B%9B%E5%95%86%E4%BD%93%E7%B3%BB&zhida_source=entity)下的极端化案例，带有一定 “怪胎” 特征（高调、跨界激进、杠杆放大）。

• 传统包税制：政府把税收征收权承包给私人 / 商人，包税人先缴固定税额给政府，然后自行多征多得。核心是收入流外包，包税人动力是过度征收，弊端是扰民、腐败。

• 追觅模式：通过 “天空工场创投” 等平台，与地方政府合作设立产业基金（LP 主要是地方国资，出资占比常达 60-80%），追觅 / 关联方出少量钱 + 品牌 / 技术 / 运营，孵化大量事业部 / 子公司（智能清洁、机器人、汽车、消费品等跨界）。项目落地当地，换取基金支持、产业园资源。核心是吸引政府股权投资 / 引导资金，而非征税。

追觅是 “基金招商” 或“资本化招商”的变种。地方政府提供耐心资本（产业基金），追觅用主业背书 + 高调包装撬动资金，快速扩张估值和版图。

为什么说它是这个体系下的 “怪胎”？

• 规模与激进度：数百家（甚至上千家）关联 / 孵化公司，跨极多行业（从电机到辣条、奶茶、房产中介都有传闻）。天空工场管理规模超 200-400 亿，地方国资主导。部分项目被指 “轻资产 + 营销包装” 为主，实际落地 / 产出存疑，导致多地近期专项摸排审计。

• 激励扭曲：地方政府急于招商（GDP、税收、就业指标），基金常有隐形返投 / 落地要求。企业可借此低成本扩张，但易出现 “拿钱包装 PPT 项目”、股权隔离（很多事业部非母公司直接持有）、资金闭环等风险。类似历史包税制的“代理人过度激励” 问题。

• 争议点：创始人高调言论 + 全员短视频等流量打法，被指是为地方政府 “表演” 看的（吸引更多基金）。主业（扫地 / 洗地机器人）全球有竞争力，但跨界造车、手机等被质疑分散精力、透支信誉。

正面看：这是中国产业政策常见模式（政府引导基金 + 企业 CVC），能快速匹配资源、降低企业融资成本。追觅主业真实出海成功，部分孵化项目也落地投产，体现了 “企业 + 政府 + 资本” 闭环。国家层面也在规范引导基金（鼓励降低返投、注重市场化）。

风险看：当扩张太快、包装过重、承诺难兑现时，就成了 “怪胎”——公共资金效率低下、潜在坏账、舆论反噬。近期多地摸排、创始人言论受限、Pre-IPO 受影响，就是例证。

总结：追觅是地方政府产业基金竞争激烈 + 企业野心结合的产物。它放大了这个体系的效率优势，也暴露了潜在弊端（资本空转、估值游戏）。类似案例在过去几年中国创投和招商中不少见，追觅因体量、风格和跨度成为典型。

\- 这样做能省多少成本？

\- 消费者受损，维权很难；

抽检结果、处罚记录、整改情况，应该让消费者查得到、看得懂、能追踪。

**什么叫纵容？** 是发现问题了，却不以为意，轻轻放过。而我们现在面对的情况，往往不是 “发现了不处理”，而是**压根没及时发现，或者疏忽了某些细节，导致积重难返**。等到最后一根稻草落下，悲剧已经发生，再处理人也晚了。

所以问题的关键，不在 “事后罚得轻不轻”，而在**事前怎么让那双侥幸的眼睛，从一开始就不敢闭上**。
